# VPN troubleshooting

This procedure applies only after loadSkill returns it. Loading it grants no tool and no permission.

Call getServiceStatus with serviceId vpn before any advice. The returned state is the input to the next step. Quote the detail field once. Do not invent a state. Do not reset a password.
