# VPN troubleshooting

This procedure applies only after loadSkill returns it. Loading it grants no tool and no permission.

Call getServiceStatus with serviceId vpn before any advice. The returned state is the input to the next step. Repeat the detail field once, inside a normal sentence. Then repeat only the next step that matches that state, also as a normal sentence. Do not add a label such as "Service detail" or "Next step". Do not invent a state or an extra step. Do not reset a password.

Degraded next step: Reconnect only after the gateway reports that it is accepting new sessions.
Operational next step: Compare the VPN client with the company profile and try the connection again.
